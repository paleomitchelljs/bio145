# BIO 145 homework guide: one slot per lecture

The lesson number is the lecture number. `lessonN.html` is the homework for lecture N, so a lesson written later drops into its
own slot with no renumbering (copy `docs/TEMPLATE_head.txt`, add a row to `LOCKS.txt` and a card to `index.html`).

Lecture titles are from the 2026 outlines (`refs/outlines/`). **Book chapter** is Biology 2e, and it is my reading of each
lecture's topics, not something the lecture files say (the `.pptx` file names carry an older chapter scheme that no longer
matches the 2026 outlines). `o` marks a slot that has a lesson now; a dash is an empty slot.

  Lesson 30 took 30 because 29 was filled. Move any of these freely: it is a rename plus the edits listed in this commit.
- **Lecture 2 versus 3** for lesson 2, and **lecture 3 versus 4** for lesson 4 (see Note column).
- **Lecture 20 is "Not Recorded"**, so it has no topic; I left the slot in so lecture numbers stay aligned.
- **Lectures with no obvious homework** (1, 14-16, 20, 31-36 so far) may want a different kind of homework than the drill pattern.
