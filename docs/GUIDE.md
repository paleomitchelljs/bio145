own slot with no renumbering (copy `docs/TEMPLATE_head.txt`, add a row to `LOCKS.txt` and a card to `index.html`).

lecture's topics, not something the lecture files say (the `.pptx` file names carry an older chapter scheme that no longer
matches the 2026 outlines). A dash is an empty slot.
